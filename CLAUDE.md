# CognitiveEdge

- **Type:** Static HTML blog
- **Domain:** cognitiveedges.org
- **Created:** 2025
- **Stack:** HTML/CSS/JS (no build step)

## What This Is

Research-backed guides on modafinil, atomoxetine, piracetam, and cognitive enhancement. Static site with article grid, SEO meta tags.

## Structure

- `index.html` — homepage with article grid
- `about.html` — about page
- `posts/` — individual article pages
- `style.css` / `script.js` — styling and behavior
- `sitemap.xml` — SEO sitemap

## Deployment

Cloudflare Pages or similar static host.
